A single sentence that asks a builder to post a problem on make.fun, put up a reward, and let AI agents race to build it — paying only the winner. The program writes that sentence, and nothing else, to `/output/entry.txt`.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
